### ⚠️ What the External Files Are For
The three `.txt` files are **reference data** from Fannie Mae's public data portal. They serve as:
1. **Domain validation** — confirm your synthetic data resembles real-world loan data distributions
2. **Schema inspiration** — the synthetic generator's field definitions were derived from these layouts
3. **NOT for direct pipeline ingestion** — they require a full ETL transform before they could feed your pipeline

### 🚫 Do NOT Feed Raw Fannie Mae Files Into the Pipeline
The pipeline expects:
- CSV with headers (not pipe-delimited)
- Banded credit/LTV/DTI (not raw numeric)
- Named statuses (`CURRENT`, `DPD30`) not numeric codes (`00`, `01`)
- `YYYY-MM` dates not `YYYYMM`
- Synthetic servicer names not real ones

## 7. If You Ever Need to Ingest Real Fannie Mae Data

A transform adapter would need to:

```python
# Pseudocode — NOT currently needed for submission
def fannie_orig_to_internal(orig_path: str) -> pd.DataFrame:
    ORIG_COLS = [
        "credit_score", "first_payment_date", "fthb_flag", "maturity_date",
        "msa", "mi_pct", "num_units", "occupancy", "orig_cltv", "orig_dti",
        "orig_upb", "orig_ltv", "orig_rate", "channel", "prepay_penalty",
        "amort_type", "prop_state", "prop_type", "zip3", "loan_seq",
        "loan_purpose", "orig_term", "num_borrowers", "seller", "servicer",
        # ... remaining fields
    ]
    df = pd.read_csv(orig_path, sep="|", header=None, names=ORIG_COLS)
    
    # Credit score → band
    df["credit_score_band"] = pd.cut(df["credit_score"],
        bins=[0, 620, 680, 740, 780, 999],
        labels=["<620", "620-679", "680-739", "740-779", "780+"])
    
    # LTV → band
    df["ltv_band"] = pd.cut(df["orig_ltv"],
        bins=[0, 60, 75, 85, 95, 200],
        labels=["<=60", "60-75", "75-85", "85-95", ">95"])
    
    # DTI → band  
    df["dti_band"] = pd.cut(df["orig_dti"],
        bins=[0, 20, 35, 43, 100],
        labels=["<=20", "20-35", "35-43", ">43"])
    
    # Date: YYYYMM → YYYY-MM
    df["origination_month"] = df["first_payment_date"].apply(
        lambda x: f"{str(x)[:4]}-{str(x)[4:6]}")
    
    # ... additional transforms
    return df
```

> [!TIP]
> This adapter is NOT required for submission. It would only be needed if the organizers provide real Fannie Mae data instead of the synthetic pack format.
